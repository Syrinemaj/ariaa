# Journal des inventions et déductions — chapitre Conception

Ce document liste, conformément à la Phase 3 de la mission, tous les éléments proposés dans `chapitre_conception.tex` (et ses diagrammes associés) qui ne sont pas directement vérifiables dans le code du dépôt.
